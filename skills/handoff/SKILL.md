# Handoff：整理交接內容

目的：使用者接下來會 `/clear` 清空對話，再把你寫的交接內容貼給新的 session。新 session 只看得到這份交接內容和 CLAUDE.md，看不到現在的對話。所以交接內容要讓一個完全沒看過這段對話的人，能直接接手繼續做。

## 步驟

### 1. 決定檔名

用 Bash 取得 app 編號（桌面版側邊欄那一項的編號，`/clear` 後不變）：

```bash
echo "$CLAUDE_CODE_HOST_SESSION_ID"
```

- 有值（例如 `local_aaaaaaaa-…`）→ 用它當編號
- 沒有值（終端機版沒有這個變數）→ 用 `cli-` 加上 `$CLAUDE_CODE_SESSION_ID` 的前 8 碼當編號，並在最後回覆中提醒使用者：終端機版 `/clear` 後編號會換，次數會從 1 重新算

次數 = `~/.claude/handoffs/` 裡已有幾個 `<編號>-` 開頭的 `.md` 檔，再加 1（資料夾不存在就是 0 個）：

```bash
mkdir -p ~/.claude/handoffs
ls ~/.claude/handoffs/<編號>-*.md 2>/dev/null | wc -l
```

日期用本地時間 `YYYYMMDD`（`date +%Y%m%d`）。

檔名：`~/.claude/handoffs/<編號>-<次數>-<YYYYMMDD>.md`

### 2. 寫交接內容

用繁體中文，第一行固定是：

> 這是從上一個 session 交接過來的內容，交接檔在 `<交接檔的完整路徑>`。需要細節時可以回去讀這個檔，或讀下面列出的關鍵檔案。

接著依序寫 7 個欄位，每個欄位都要有；真的沒有內容就寫「無」：

```markdown
## 1. 目標
這個任務最終要做到什麼，一兩句話。

## 2. 目前進度
做完了什麼、做到哪一步。已完成的寫明證據（測試結果、讀回的檔案）。

## 3. 決定與理由
選了什麼做法、為什麼這樣選。每一條都要有「為什麼」。

## 4. 試過但失敗的做法
做法、失敗的原因。避免新 session 再走一次。

## 5. 關鍵檔案
- `絕對路徑:行號`：一句話說明用途

## 6. 未解決的問題與下一步
依優先順序列出。下一步要具體到新 session 可以直接開始做。

## 7. 使用者在這次對話中講過、但還沒寫進 CLAUDE.md 的偏好
只列 CLAUDE.md 裡沒有的；CLAUDE.md 已有的規則不要重複。
```

**不要放：** 完整對話紀錄、工具輸出原文、CLAUDE.md 已經有的規則。只寫新 session 接手需要的東西。

**不確定的事寫「尚未驗證」**，不要寫成已完成。

### 3. 存檔並讀回

1. 用 Write 把交接內容寫到步驟 1 的檔名
2. 用 Read 讀回，確認內容完整、7 個欄位都在

### 4. 回覆使用者

只回覆這三行，不要重貼交接內容：

```
交接檔：<完整路徑>（已讀回，7 個欄位都在）
接下來：/clear，再把交接檔的內容貼進輸入框，看過後送出。
下一步：打開交接檔確認內容，沒問題就 /clear。
```
